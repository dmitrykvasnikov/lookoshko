# Lookoshko

Android-приложение для знакомства с историей зданий и памятников рядом с пользователем.

Первый пилот: центр Калининграда. Первые объекты: главный корпус КГТУ и бывшая Кёнигсбергская биржа.

## Состояние проекта

Подготовлена документация для начала разработки. Исходного кода приложения, сборки APK и серверной части пока нет. Для технического прототипа принята бесплатная схема MapLibre + OpenFreeMap, системная геолокация Android, локальный поиск и системный Text-to-Speech. Основной Android-стек, минимальная версия Android и расширенное поведение аудио ещё нужно согласовать.

Ближайший результат: устанавливаемая Android-сборка с двумя объектами, поиском рядом, текстом и озвучкой. Пользовательские публикации и рейтинги входят в следующий этап MVP.
