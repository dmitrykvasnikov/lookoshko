# Контент пилота: центр Калининграда

Материалы ниже — заготовка исследования. Они ещё не являются готовым набором данных приложения.

## Первые объекты

### Главный корпус КГТУ

Рабочая идентификация: Советский проспект, 1, бывший комплекс Земельного и Административного суда Кёнигсберга. Уточнить, какую часть комплекса описывает карточка: разные части строились в разное время.

Источник для проверки:
https://visit-kaliningrad.ru/entertainment/sights/gorodskie-zdaniya/kgtu-kompleks-zdaniy-zemelnogo-i-administrativnogo-suda/

Перед публикацией: проверить даты и атрибуцию архитектора для выбранной части здания, адрес, координаты и фотографию фасада.

### Бывшая Кёнигсбергская биржа

Рабочая идентификация: здание, в котором располагается Калининградский музей изобразительных искусств. В исходном обсуждении пользователь назвал объект «Морской биржей»; это название можно рассмотреть как поисковый синоним после уточнения.

Источник для проверки:
https://www.kaliningradartmuseum.ru/about/history-of-the-museum-building/

Темы справки: строительство в 1870–1875 годах, Генрих Мюллер, торговая и культурная жизнь, львы Эмиля Хундризера. Перед публикацией перепроверить факты, адрес и координаты.

## Материалы для каждого объекта

- Название, альтернативные названия и адрес.
- Проверенные широта и долгота; не использовать вымышленные координаты.
- Современная фотография, автор и разрешение / лицензия на использование.
- Краткий рассказ на 45–90 секунд и при необходимости подробный текст.
- Отдельные поля известных фактов: период строительства, архитектор, прежнее назначение.
- Ссылки на источники и дата их проверки.
- Статус редакторской проверки; неопределённости и легенды обозначены явно.

Тексты пересказываем самостоятельно. Фотографии и длинные фрагменты источников без проверки прав в приложение не переносим. Озвучку проверяем на произношение имён, исторических названий и дат.
