## Бесплатная техническая схема прототипа — 2026-09-07

**Статус:** принято для технического прототипа. Окончательный картографический сервис для публичного выпуска будет подтверждён после проверки качества и доступности прототипа.

**Решение пользователя:**

- отображать карту через MapLibre Native;
- использовать публичный сервис OpenFreeMap как источник векторных тайлов;
- получать местоположение через системные API Android без обязательной зависимости от Google Play Services;
- искать два пилотных объекта по локальным данным приложения, не подключая внешний геокодер или Places API;
- использовать системный Android Text-to-Speech без облачного сервиса озвучки;
- не создавать сервер для демонстрационной сборки;
- изолировать источник карты от интерфейса, чтобы его можно было заменить без переделки экранов.

**Рассмотренные варианты:** Google Maps SDK с ключом и включённым биллингом; собственное размещение картографических тайлов; MapLibre с бесплатным публичным источником тайлов.

**Обоснование:** выбранная комбинация позволяет проверить основной сценарий без оплаты внешних сервисов, банковской карты и преждевременной серверной инфраструктуры. MapLibre не привязывает интерфейс к одному поставщику карт, а локальный каталог исключает расходы на поиск и геокодирование.

**Проверенные источники на дату решения:**

- https://openfreemap.org/
- https://maplibre.org/maplibre-native/android/api/
- https://operations.osmfoundation.org/policies/tiles/

**Последствия и ограничения:**

- на карте всегда показывается требуемая атрибуция OpenFreeMap, OpenMapTiles и OpenStreetMap;
- публичные серверы `tile.openstreetmap.org` не используются как источник тайлов приложения и не применяются для офлайн-предзагрузки;
- OpenFreeMap не предоставляет SLA, поэтому ошибка или недоступность карты не должна блокировать список, карточки и чтение рассказов;
- адрес стиля и источник тайлов не зашиваются в UI и заменяются в одном месте конфигурации;
- системный TTS может отличаться на разных телефонах; пауза, продолжение, фоновое воспроизведение и работа без загруженного русского голоса остаются предметом эксперимента;
- серверная платформа и её бесплатный тариф не выбраны: решение откладывается до успешной полевой проверки двух объектов;
- перед публичным выпуском повторно проверяются условия сервиса, доступность на целевых устройствах и необходимость резервного картографического поставщика.

## Предложения для начала разработки

- Kotlin + Jetpack Compose.
- Две ступени: сначала сборка с готовым контентом, затем MVP с публикациями и рейтингом.
- Просмотр без входа, аккаунт для публикаций и оценок.
- Проверка материалов перед публичной публикацией.
- Оценки «Полезно / Не полезно».

Эти предложения не следует считать окончательно утверждёнными техническими решениями.

## Решить до первой Android-сборки

1. Основной Android-стек, минимальная версия Android и телефоны для проверки.
2. Результаты проверки MapLibre + OpenFreeMap на целевых телефонах; окончательное решение для выпуска принимается позднее.
3. Требования к системной озвучке: пауза, блокировка экрана и работа без загруженного русского голоса.
4. Макеты, оформление и рабочее название в интерфейсе; Lookoshko пока название проекта.
5. Точные границы объекта КГТУ, координаты, фотографии и проверка исторических фактов.

## Решить перед общим контентом

1. Способ входа и размещение сервера, бюджет эксплуатации.
2. Кто проверяет публикации и какие источники принимаются.
3. Правила правок, фотографий, авторства, жалоб и удаления аккаунта.
4. Формула рейтинга, видимость новых рассказов и судьба оценок после существенной правки текста.
5. Магазин и способ распространения тестовых сборок.
