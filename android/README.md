# Android-приложение

Место для будущего Android-проекта. Kotlin + Jetpack Compose остаются предложением до отдельного согласования основного стека.

Сборка ещё не настроена. Здесь пока нет Gradle-проекта, исходников и APK.

На этапе реализации добавим модуль app, Gradle Wrapper, закреплённые версии зависимостей и инструкцию запуска. SDK-пути и секретные ключи не хранятся в Git.

Для технического прототипа приняты MapLibre Native, тайлы OpenFreeMap, системное местоположение Android, локальный поиск и системный Text-to-Speech. Сервер и внешние сервисы геокодирования в демонстрационную сборку не входят. Источник карты должен быть заменяемым, а отсутствие карты не должно блокировать локальный список и рассказы.

До генерации основного проекта нужно проверить доступные инструменты разработки, согласовать основной Android-стек и минимальную версию Android, а также экспериментально уточнить поведение озвучки. План: [docs/development-plan.md](../docs/development-plan.md).
