# Android-приложение

Место для будущего Android-проекта на Kotlin с Jetpack Compose.

Сборка ещё не настроена. Здесь пока нет Gradle-проекта, исходников и APK.

На этапе реализации добавим модуль app, Gradle Wrapper, закреплённые версии зависимостей и инструкцию запуска. SDK-пути и секретные ключи не хранятся в Git.

До генерации проекта нужно проверить доступные инструменты разработки и выбрать карту, минимальную версию Android и способ озвучки. План: [docs/development-plan.md](../docs/development-plan.md).
